About the Project

Problem Statement

Design a software/simulation solution for “ROM-Based Lookup Table for Feature Transformation” using a digital-system concept and reproducible synthetic data.

Objective

Demonstrate input-to-output mapping using ROM, validate the result using a formula-based transformation, and provide testable outputs, analytics and documentation.

Digital System Concept

A 4-bit input selects one of 16 ROM addresses. The value stored at that address becomes the transformed output.

Technology Used

Python Flask HTML CSS JavaScript NumPy Pandas Matplotlib Jupyter

Reference Formula

Y = (3X + 5) mod 16
The supplied ROM mapping is a synthetic example. If your faculty has given a specific mapping or formula, update data/rom_table.csv and formula_transform() in app.py.
